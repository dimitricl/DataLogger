Information SPI (Serial Peripheral Interface) Le protocole SPI utilise 4 signaux principaux pour communiquer :
  • CS : Selectionne le composant a utiliser (ici la carte SD).
  • MOSI : Maitre (Arduino) envoie au slave (SD).
  • MISO : Slave (SD) repond au maitre (Arduino).
  • SCK : Horloge synchronisant les transferts.

Precautions importantes
  • Verifiez que les branchements sont corrects AVANT d'alimenter.
  • Utilisez une tension stable de 5V pour la SD (risque de corruption de donnees).
  • Tous les GND doivent etre connectes ensemble (Masse commune).
  • La carte SD doit etre formatee en FAT32.
  • Deconnectez l'Arduino avant de brancher/debrancher la SD physiquement.
  • Les broches 11, 12, 13 sont dediees au SPI (ne pas modifier).

6. Procedure de montage

  1. Arretez l'Arduino (debranchez le cable USB).
  2. Preparez la breadboard et les cables.
  3. Connectez le SD Shield sur la breadboard.
  4. Reliez Arduino vers SD Shield (5V, GND, Pin 5, 11, 12, 13).
  5. Branchez les capteurs analogiques (A0, A1).
  6. Inserez la carte SD (formatee FAT32) dans le shield.
  7. Reconnectez l'Arduino en USB.
  8. Televersez le code (ParkingBarrierDemo.ino).
  9. Verifiez les messages dans le Serial Monitor (115200 bauds).
Verifications post-montage
  • Serial Monitor affiche "Initialisation... OK".
  • Les logs sont crees et visibles sur la carte SD.
  • Les valeurs de capteurs varient dans une plage raisonnable.
  • Pas de message d'erreur apres 1 minute de fonctionnement.
